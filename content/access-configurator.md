# 门禁配置器

<entity id="AccessConfigurator" caption="门禁配置器"></entity>

门禁配置器用于设置哪些人员可以使用气闸、保险箱、储物柜和受限机器。气闸也可以用网络配置器或多用工具配置。

每座空间站最多有两台：一台由总工程师持有，一台由人事主管持有。

## 使用

- 对目标设备使用配置器建立连接并打开界面。
- 插入 ID。
- 修改设备权限。可添加或删除哪些权限取决于 ID 自身权限。
- 修改立即生效；完成后取出 ID 并关闭界面。

## 修改限制

插入的 ID 必须拥有目标设备当前**全部**权限，才能修改。例如同时受科研部和医疗部权限保护的门，只能用同时拥有两项权限的 ID 修改。未设权限的公共设备可用任意有效空间站 ID 修改。

## 修复门禁读取器

辛迪加门禁破解器会短路 ID 读取器，使设备变为全通行。

<entity id="AccessBreaker"></entity>

通常需要部分拆解并重建设备，以恢复默认权限。

气闸若有配置器，可用螺丝刀打开维护面板后直接重新配置；没有配置器时，需要拆到门电子元件再重建，以恢复班次开始时的默认权限。
