# 如何游玩 SS14

<entity id="SignSecureMedRed" caption="内容与主题警告"></entity>

**游戏内容包括：** 绑架、诱拐、谋杀、巨型蜘蛛、精神控制、像素化血腥内容及像素化裸露。

## 简介

你刚刚开始在 NanoTrasen 研究空间站上的一个班次。这座空间站位于 Starlight 企业星区边缘。虽然空间站属于 NanoTrasen，但公司已经离开约 50 年，目前由一家名为 Central Command 的承包公司负责运营。

作为 Central Command 的员工，你通常受 PSO 克隆保险计划保障。原身体会被安全保存，代替你工作的是克隆体。如果你能在班次结束时返回 Central Command，记忆就会被转移回原身体。

你和船员们需要共同合作、活下来，并享受这一班次。

**请遵守所有服务器规则。** 有疑问或遇到违规行为时，可以使用 **管理员帮助菜单（Admin Help, AHelp）** 向管理员团队提问或报告。可以在控制设置中查看 AHelp 的绑定键。

关于具体岗位和机制的详细指南，可以在 Guidebook 的其他页面中查看。

打开指南书的快捷键同样可以在控制设置中查看。

## 基础操作

常规游戏需要掌握以下操作：

- 使用 <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> 移动；按住 <kbd>Shift</kbd> 慢走。
- 使用 <kbd>Shift</kbd> + 左键检查周围的事物。
- 使用左键与世界互动。
- 将鼠标悬停在实体上并按右键，可以打开**上下文菜单（Context Menu）**，其中包含更多互动选项。
- 使用 <kbd>X</kbd> 切换左右手，使用 <kbd>Z</kbd> 激活当前手持物品。
- 使用 <kbd>Q</kbd> 放下手中物品，也可以将物品投掷到鼠标位置。
- 使用 <kbd>Ctrl</kbd> + 左键拉动物品，松开拉动也使用相应快捷键。

完整操作说明见[操作控制](controls.html)。

## 什么是 SS14？

Space Station 14 是一款围绕太空站上的猜疑与混乱展开的多人游戏，也是经典游戏 Space Station 13 的重制版。

你可以和数十名玩家一起进入一座精细模拟的空间站，参与角色扮演，并处理沿途出现的各种威胁。

SS14 是一款由社区开发者维护的开源游戏，几乎每天都会更新，因此部分版本也可能暂时不稳定。

如果想报告漏洞或参与开发，可以加入 Discord，了解如何开始贡献。
