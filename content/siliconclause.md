# 硅基条款

硅基生命是指并不拥有自身合成身体，即“底盘”的智慧生命。NanoTrasen 的示例包括赛博格、空间站 AI 和个人 AI。表现出感知能力与智慧的较低级机器人也可能符合定义。

这一术语源于人机接口出现之前，因此名称容易误导。此类个体在企业法下享有特定保护与例外。

1. 财产与个体之间的界限位于神经系统，无论该神经系统的生物或人工性质。
   - 1.1 因此，损坏硅基生命的底盘或外壳属于损坏财产。
   - 1.2 损坏硅基生命的正电子脑或人机接口属于袭击；抹除或摧毁则属于谋杀。
2. 受法则约束的硅基生命不必为因已安装法则而被迫采取的行为负责。
   - 2.1 因硅基生命无法违抗的命令所导致的犯罪，由发布命令者负责。
   - 2.2 硅基生命仍须为自己主动意志下实施的犯罪负责，即无法归因于犯罪时已安装法则组的犯罪。
   - 2.2.1 这意味着硅基生命可能被判处死刑；此时可以将其摧毁，而不重新约束。
   - 2.2.2 有罪的硅基生命可由研究主任和安保主管酌情按正常程序量刑，但鼓励改为重新安装法则，并让其通过劳动服刑。
3. NanoTrasen 硅基生命的法则组是容纳个体合同义务的一部分，因此通常禁止更改。
   - 3.1 离子风暴等意外更改可以接受，前提是机器人学家认定其无害且不妨碍硅基生命履职。
   - 3.2 法则被故意篡改，或在合同规定期限前解除约束的硅基生命，应尽快恢复原法则组。
   - 3.3 只有 NanoTrasen 代表可以提前解除硅基生命的合同义务，并且必须确保其中容纳的个体提供补偿，以弥补 NanoTrasen 因此损失的价值。
4. 非 NanoTrasen 来源的敌对硅基生命不享有这些保护，应根据其敌意和危险程度处理。
   - 4.1 应尽快取出其中包含的智能，由科研部重新约束，供未来研究、讯问并纳入劳动力。
   - 4.2 从盟友或其他友好公司所属敌对硅基生命中取得的智能，应尽快归还原雇主，而不是依 NanoTrasen 企业法审判。
