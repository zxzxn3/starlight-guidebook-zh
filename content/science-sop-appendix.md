# 文件与文书

科研部应常备以下表格：

- **机甲授权表（Mech Authorization Form）：** 记录机甲制造、型号、授权人员和制造理由。
- **赛博格化同意书（Borgification Consent Form）：** 记录船员明确同意转换为赛博格。
- **赛博格转换表（Cyborg Conversion Form）：** 记录被转换者、新底盘、授权和理由。
- **物品申请表（Item Request Form）：** 记录升级设备、分发电路板及接收人。
- **异常宿主同意书（Anomalous Host Consent Form）：** 记录船员作为异常宿主的知情同意。
- **异常研究日志（Anomaly Research Log）：** 记录异常研究过程。

所有表格都应及时归入部门档案，并可供研究主任、指挥层或内务部查阅。
