# 囚犯待遇

1. 没有有效判决时，不得关押囚犯。判决必须满足以下条件才算有效：
   - 1.1 明确指出违反了企业法的哪一部分。
   - 1.2 明确指出违反该法律的具体方式。
   - 1.3 被监狱长或安保主管听到并明确批准。
   - 1.4 向囚犯本人完整宣读。
2. 执行逮捕的警员负责确保囚犯不会把危险装备或有助于越狱的工具带入安保区。警员必须搜查囚犯并没收相关装备。
3. 必须没收囚犯的 PDA，并在关押期间发给其囚犯 ID。
4. 刑期结束后，必须归还囚犯所有未被没收的财物，包括 PDA。
5. 默认情况下，囚犯在安保区不应受到束缚；如果囚犯过度失控，可以重新束缚。
6. 囚犯可以要求审判，但只有在刑期为永久、死刑，或被指定为公司之敌时，才有权获得审判。
7. 囚犯可以随时要求律师；如果有律师在岗且愿意前来，囚犯有权接受探视。
