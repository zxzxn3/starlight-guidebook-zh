# 科学家 SOP（Scientist）

<entity id="ToyFigurineScientist" caption="科学家"></entity>

1. 科学家（Scientist）直接向研究主任报告。
2. 研究时应遵守基本安全程序，例如：可能释放气体时佩戴内呼吸装备，可能爆炸时穿防爆服，并对危险材料进行收容。
3. 应将潜在危险告知船员，包括异常生成、可能的爆炸、失控神器等。
4. 科学家应指导附近的研究助理，并对他们的安全负责。
5. 研究助理参与高风险任务时，科学家应近距离监督并给出更详细指导，避免发生意外危险。
