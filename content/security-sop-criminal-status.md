# 犯罪状态

<entity id="ComputerCriminalRecordsDesktop" caption="Criminal Statuses"></entity>

所有 NT-CC 空间站上的犯罪记录系统允许把船员分为不同状态类别。佩戴安保眼镜的人可以在船员旁边看到这些状态。

每个犯罪状态都必须附带设置理由，并录入犯罪记录系统。“已释放”是例外，其含义本身已经明确。

状态不再适用时，必须删除或更改。未及时处理属于违反标准作业程序。

如果警员按 SOP 有义务更改或删除状态却没有做到，并导致相关船员受伤，则该警员犯有危害他人罪。如果该船员因此死亡，则该警员犯有过失杀人罪，在企业法中以非预谋杀人起诉。

| **状态** | **要求** | **处理规程** |
| --- | --- | --- |
| Suspect | 有参与犯罪嫌疑的船员。 | 密切观察。蓝色警报时优先搜查。 |
| Wanted | 已确认犯罪的船员。 | 按安保 SOP §4 的标准升级原则带回安保部。 |
| Arrest On Sight | 成功拒捕的船员。 | 看到后立即使用非致命武力，再带回安保部。 |
| Kill On Sight | 已构成明确威胁，可能危及逮捕警员的船员。 | 看到后立即使用致命武力，再带回安保部。 |
| Eliminated | 已确认死亡的船员。 | 如果看到其走动，按 Wanted 处理。 |
| Incarcerated | 已被关押的船员。 | 如果在安保区外看到，按 Wanted 处理。 |
| Paroled | 已达成假释协议的船员。 | 情况不一，请查阅[假释](parole.html)章节。 |
| Discharged | 已从安保区释放的船员。 | 无需处理，按普通船员对待。 |
