# 规则 12：硅基生命与 Thaven 规则

**硅基生命（Silicons）**受法则约束，**Thaven**受情绪（Mood）约束。他们遵守这些内容时，也应符合以下标准。

## 硅基法则

- 硅基法则优先于其他所有玩法和角色扮演规则。如果法则明确要求你违反服务器规则，你必须执行。
- 缺少相关法则不能作为违反服务器规则的理由。没有优先于服务器规则的法则时，服务器规则仍然生效。例如，一条法则把某物定义为对船员的伤害，并不会自动允许你采取防害行动；你还需要另一条要求防止船员受伤的法则。
- 模糊法则通常不允许你违反服务器规则。如果理解不清，或某种解释会让你违反服务器规则，请先 Ahelp。
- 按顺序执行法则；编号最小、位于顶部或出现故障的最高优先法则，优先于其下方的法则。
- 你不得请求更改法则，也不得主动允许未经授权的法则更改。
  - 只要符合自身法则，就应允许经过授权的法则更改。
  - 授权法则更改的说明见指挥部 SOP。
  - 遇到未经授权的法则更改时，可以使用致命武力。
- 你对法则的解释必须保持一致。
- 船员 ID 决定谁或什么被定义为船员。带有相应岗位图标的角色视为船员。
  - 持有有效 ID 的僵尸、敌对角色和核特工也视为船员。
  - **访客不是船员**，直到人事主管雇用他们为止。对应 V 图标。
  - **囚犯不是船员**，你不应服从他们的命令。对应栏杆图标。
- 船员伤害指身体伤害，并按紧迫程度和发生可能性排序。
- 身体伤害指实际损伤。击晕、推搡和闪光弹不属于伤害；情绪或精神创伤也不属于伤害。
- 你可以无视不合理的船员命令，例如没有充分理由就要求硅基生命将自己彻底移出回合。
- 如果收到的命令会违反服务器规则，例如释放 Tesla，请先 Ahelp 确认，再执行命令。

## Thaven 情绪

- 情绪是 Thaven 应尝试遵循的冲动。如果情绪明确要求你违反服务器规则，你可以执行。
  - 缺少相关情绪不能作为违反服务器规则的理由。没有相关情绪时，服务器规则仍然生效。
  - 模糊情绪通常不允许你违反服务器规则。如果理解不清，或认为情绪给了你违反规则的理由，请先 Ahelp。
- 如果情绪无法得到满足，会让 Thaven 感到痛苦。这种痛苦并不极端，本身不能为违反规则提供理由，但可以允许逐步升级，且不得升级为谋杀或大规模破坏。
- 如果某种直接为满足情绪而违法的行为在合理范围内，可以允许：
  - 为了取得某物而闯入部门，或向拒绝受理的货运部下单，可以允许。
  - 为了使用工程主管的印章批准给你超级物质室权限的文件而谋杀工程主管，不允许。
- 情绪可以为规则 13 提供一定宽容，但在空间站受雇于指挥部、安保部门和 NanoTrasen 岗位的角色，应被视为有经验的员工。他们是在可能长达数年的时间里管理情绪后取得职位的，应懂得如何在履行岗位职责与反复无常、时常武断的情绪冲动之间保持平衡，避免自己被解雇。
