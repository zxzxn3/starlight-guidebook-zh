# 人质事件

CC 员工合同包含保护所有员工安全的条款。员工被劫持为人质时，安保与指挥层必须努力确保员工活着返回。

1. 除非明确说明并非如此，所有都应推定植入了死亡开关；人质死亡时身体会被摧毁，导致该克隆永久死亡。
2. 不应尝试会导致人质死亡、之后再复活并回收身体的救援行动。
3. 如果绑匪索要赎金，舰长或安保主管可以协商使用空间站资金、物品，或两者组合交换人质安全返回。交易总价值，即物品与资金合计，不得超过本节末尾表中规定的数值。
4. 如果安保手中有一名敌对势力成员，可以用其交换人质。
5. 所有人质谈判都必须包含敌对势力停止活动并撤离该区域的保证。
6. 如果安保确信能够安全救援，可以尝试解救人质。直接冲入现场与敌人交火属于鲁莽行为，可作为降职依据。
7. 可接受的救援方式包括但不限于渗透、以非暴力手段使敌人失去能力，或利用干扰在不交战的情况下解救人质。

## 赎金协商上限

| 金额 | 岗位 |
| --- | --- |
| 10k | 任何有岗位的船员 |
| 15k | 指挥层成员 |
| 20k | 舰长 |
| 25k | 治安法官、NanoTrasen 代表、内务部探员和蓝盾军官 |
