# 规则 16：回合结束后的恶意破坏

结算界面出现后，回合仍在继续。此时船员和敌对角色都不得在没有 IC 理由的情况下实施任何暴力或恶意破坏。

对于僵尸、核特工、独行特工等情况，如果本规则暂停适用，管理员会解除和平状态并明确说明。

- 自卫属于 IC 理由；安保逮捕已知罪犯也属于 IC 理由。
- 敌对角色在结算界面后无法完成任务，因此不应继续寻找目标。出现红色结算提示意味着你已经失败，为时已晚。
- 在没有恰当 IC 理由时，不得破坏物品、黑入或使用 EMAG，也不得试图闯入中央指挥部的指挥简报室。非指挥人员若无有效理由且拒绝离开，可能被处决。
- 不得使用金属泡沫手雷、润滑手雷或润滑泡沫等非致命手段干扰收尾角色扮演。
- 不得从其他玩家身上偷取物品。执行检查站的 ERT/NTSF，或没收违禁品的安保不在此限。
