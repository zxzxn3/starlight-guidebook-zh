# 规则 0：保持尊重

请自行判断怎样做才能维持有趣、公平且友好的环境。所有争论都应保持在 IC 范围内；不要在 LOOC、Ahelp 或大厅中展开激烈争吵。OOC 交流始终应保持尊重和友善。

骚扰或有害行为包括但不限于：

- 种族主义、性别歧视和其他歧视。
- 过度谈论或美化自残。
- 讨论现实生活中的政治。
- 跨越多个回合针对同一名玩家。
- 在 OOC、LOOC 或死亡聊天中侮辱其他玩家。
- 利用 LOOC、OOC 或死亡聊天抱怨 IC 情况，也就是“malding”。
- 过度使用 LOOC 来执行规则。
- 威胁 Ahelp，以改变一次角色互动的结果。
- 在被纠正后仍故意、反复地错误称呼他人性别。
- 对某个种族进行超出典型刻板印象式玩笑的虐待或贬低。

这些行为不会被容忍，并可能导致永久封禁。

发现有害行为或违规行为时，通过 Ahelp 报告通常比亲自介入或执行规则更合适。你可以提醒某人一次，说明其行为可能违反规则；持续解释规则或试图充当规则律师则不允许。也不得威胁“除非你改变行为，否则我就 Ahelp”；报告问题后继续游戏即可。

关于允许和不允许的“种族主义式扮演”，进一步说明如下。

可以接受的典型化示例：

- “给我来杯酒，酒保！你知道对矮人来说一杯可不够！”
- “*叹气*……Shadekin 又把灯弄坏了……”
- “你是讨厌植物的 Diona？这到底怎么做到的？”

不可接受的种族主义示例：

- “你这脏杂种，别把我的酒吧弄得全是毛。”
- “尖耳朵的混蛋，当初就不该让你们这种人进招募处。”
- “蜥蜴人就是未进化完全的物种。”
- “他们到底怎么会让你这种人进指挥部？”（此处指种族，请结合语境判断。）
