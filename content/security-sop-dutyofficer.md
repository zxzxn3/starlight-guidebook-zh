2. 如果需要镇压安保区骚乱，值班官可以在绿色警报下使用并穿戴防暴装备和武器。
3. 值班官负责协助监狱长完成所有职责，并直接向监狱长报告。没有监狱长命令时，其主要职责按重要程度排列如下：
   - 3.1 协助镇压安保区骚乱。
   - 3.2 协助保护安保区及整个安保部。
   - 3.3 协助维护犯罪记录系统。
   - 3.4 保障囚犯和被拘留者的健康与福祉。
   - 3.5 在安保部内利用犯罪记录系统和船员监控系统协助现场警员。
4. 值班官有权把已判刑罪犯关押在安保区最多 **15 分钟**。
   - 4.1 判决必须向监狱长或安保主管口头宣读才能生效。如果通过无线电宣读，必须得到可听见的确认。
   - 4.2 值班官尤其有责任确保这些判决被正确归档。
