# 规则 15：角色与玩家的分离

玩家会在游戏外建立关系和交流方式。这些互动不应影响回合内发生的事。

**元友（Metafriending）与元仇（Metagrudging）**

- 基于角色不应知道的信息，给予某名玩家或角色特殊待遇，属于元友。
- 基于角色不应知道的信息，负面对待某名玩家或角色，属于元仇。

**仅限英语**

- 游戏内的任何交流都应使用英语，以便所有玩家理解。可以偶尔借用其他语言的单词作为常见表达，但句子的核心含义必须用英语说明。

**场外通讯（Metacomms）**

- 禁止通过游戏外方式与其他玩家交流当前回合的信息。唯一例外是教导新玩家，但必须事先通过 Ahelp 告知管理员。
