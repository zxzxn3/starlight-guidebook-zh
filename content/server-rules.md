# 服务器规则

以下规则适用于 Starlight Space Station 14 服务器。违反规则可能导致警告、临时封禁或永久封禁，也可能被禁止游玩特定角色、岗位或部门。封禁可以在 Starlight 官方 Discord 服务器申诉。

玩家也应理解[元信息屏障（Metashield）](metashield.html)。规则和元信息屏障的最新版本通常会发布在 Starlight Wiki。

如果你不确定某件事是否违反规则，可以通过管理员帮助（Admin Help, AHelp）联系管理员，或在 Discord 询问。

游戏内的法律和程序请查看企业法与 SOP。

请注意，本页列出的规则和示例并不穷尽所有情况，参见规则 1。

服务器严格要求玩家年满 **16 岁**。

死斗和沙盒模式可能不适用这些规则；如果有变化，服务器会另行说明。幽灵聊天是游戏内的一种 OOC 聊天，不需要遵守 MRP 规则。
