# 艾利希人（Aielithii）

<entity id="MobElf"></entity>

艾利希人是 NanoTrasen 二十多年前派入 Null Scar 的一支舰队后代。舰队进入现实裂缝后，那里已经过去了一万多年，足以让帝国兴衰、科学体系被发现又遗忘，也让无数战争发生在物理规律都会失效的奇异星球之间。他们大体仍属于人类，但肤色多样，并因长期接触和部分掌握 Null Scar 的奇异能量，形成了独特文化。

尖耳和跨度极大的肤色很容易辨认艾利希人。他们极其长寿，有人据称能活数千年。由于 Aielithii 很难拼写，人们常称他们为精灵；不过也有人反感被比作虚构生物。

## 族群

如今主要有四个艾利希族群，历史上还有许多群体已经边缘化或灭绝。角色创建时建议选择族群，不选没有优势。

**Quela**：Queli 是 Quelani Worlds 中哲学家、科学家和探险家的后裔。母语为 Aielic，诗歌无人能及。多数来到 Starlight 星区的 Queli 参与了 MAGE 收集巫师联合会情报的任务。

**Laurasse**：Laurassi 以栽培植物为荣，成长时身边都是 Null Scar 的 Diona，并将其视为挚友。母语 Sylvan 通过树木的智慧流传至今。对 Laurasse 来说，金属飞船像牢笼。其绿色母星名为 Tavas。

**Seiryth**：随着世代推移，一些困在 Null Scar 的人不断深入裂缝，试图掌握其中危险而神秘的秘密。他们被称为 Seirythii，领袖称 Seiryth Monarchs，在不适合生存的暴烈星球上的坚不可摧堡垒中统治。来到 Starlight 星区后，他们惊讶地发现许多邪恶生物早已会说母语 Darktongue。

**Detar**：其他族群争夺 Null Scar 的事件视界时，Detarii 在据称无法生存的暗星定居。他们深入岩层，依靠地热生活。在那里适应黑暗并等待夺取终极力量的机会。母语 Felyaic 与 Darktongue 很接近，但只有 Detarii 和 Seirythii 理解其独特之处。

所有艾利希人都有一点微光视觉，但这依赖 Null Scar。因此在空间站上，他们在黑暗中和人类一样看不见。

## 法术

所有艾利希人都能操纵一部分从 Null Scar 泄漏到现实中的能量。他们称这种力量为 arexis，也就是“帮助”，但外界通常直接叫魔法。它与巫师联合会繁复的把戏完全不同。

艾利希人每班次开始时会拿到一本精简魔法书，其中有几个帮助生存的小法术。可以选择两个记忆到班次结束。读完魔法书后通常就可以丢弃；其他人无法阅读或学习你的魔法书。如果能让效忠巫师联合会的巫师取出 WizCoins，也许还能掌握更多法术。

## 伤害

在 Null Scar 中生活数千年后，艾利希人的身体已经受到裂缝和自身技艺改变。由于骨骼脆弱，他们通常避免近战，受到的钝击伤害高 20%。古代基因改造则使他们受到的毒素伤害低 25%，细胞衰变伤害低 10%。

## 背景

2501 年，NanoTrasen 科学家认为可以深入 Null Scar 建立研究前哨。一支配备先进护盾、多年补给以及数千名优秀人员的庞大舰队被派入裂缝，试图彻底掌握这片边疆。舰队随后失踪。NT 隐瞒了事件，从历史书中删除姓名，并把发明和奖项归给别人。

二十四年后，一些无聊的巫师联合会年轻人穿过 Null Scar。他们显然触动了什么；不久后，自称艾利希人的尖耳类人生物开始抵达 NT 空间站，询问关于巫师力量以及如何阻止他们的奇怪问题。

如今联合会似乎正与一个较有冒险精神的艾利希组织交战：Magistracy of Aethyrically-Gifted Explorers。该组织成员来自各个族群，但主要由 Quelani Worlds 推动，因为他们非常反感所谓巫师的幼稚行为。

NanoTrasen 认为自己有权取得最初资助的研究成果。这种外交态度至今没有取得期望结果。
