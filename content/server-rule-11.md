# 规则 11：新生命（New Life）

新生命系统允许玩家死亡后以新角色重新加入回合。为了维持公平和代入感，该系统带有角色扮演限制。

以新角色重生后，你会忘记旧角色或幽灵形态知道的一切：

- 不得寻找旧身体、返回旧工作地点，或尝试取回旧角色拥有的物品。
- 不得与导致旧角色死亡的玩家互动。前世发生的冲突或怨恨不得延续。
- 不得以任何方式提及过去事件。新角色对这些事没有记忆。

## 滥用新生命的示例

- 利用新生命故意刷敌对角色槽位。
- 作为非敌对角色利用新生命逃避 IC 后果。
- 使用新角色向伤害过你的玩家复仇。

此外，不得通过变成幽灵和新生命系统逃避 IC 处罚，例如监禁或停职。

- **逃避处罚（Leaving To Avoid Punishment, LTAP）**：被安保抓住后变成幽灵并使用新生命，不允许。永久囚犯可以在合理范围内获得例外。

如果玩家因现实原因必须在这些情况下离开，应通过 LOOC 消息告知周围玩家，或在 Ahelp 中说明。
