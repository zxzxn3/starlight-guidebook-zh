# 公司之敌

公司之敌是指所有能够证明与某个企图通过欺诈或武力破坏 NT-CC 事业的组织有关联的人。

示例包括：

- 辛迪加特工及其盟友。
- 经 USSP 训练的渗透者。
- 企图非法解放 NT-CC 财产的 SELF 激进派成员。
- 吸血鬼或邪教徒等超自然敌对阴谋组织成员。

## 非船员

敌对登船者等非船员入侵者自动属于公司之敌，可以随时交战。

## 船员

船员必须因被起诉的犯罪累计至少 4 点，并且与敌对组织存在实际关联。

每项被起诉犯罪的点数由犯罪严重等级决定：

| **等级** | **点数** |
| --- | --- |
| 1-XX 轻微 | 0 |
| 2-XX 中度 | 0 |
| 3-XX 重大 | 1 |
| 4-XX 极端 | 2 |
| 5-XX 死刑 | 3 |

适用企业法的标准规则：关联犯罪不能同时起诉，因此只有实际被起诉的犯罪才能产生点数。

这种关联可以通过两种形式证明：

- 实物证据。
- 供认。

### 实物证据

实物证据必须直接关联敌对组织本身，共有三种形式：

- 可关联到敌对组织的行为，例如使用自由电磁枪或饮血。必须至少有两名可信人员目击才能采用。
- 与敌对组织相关的违禁品，例如自由电磁枪或已打开的上行链路。
- 证明其效忠的阳性检测，例如思维护盾植入失败、植体取出，或对吸血鬼进行阳光/圣水测试。

### 供认

供认可以是口头或书面形式，但必须有至少两名已植入思维护盾的安保人员见证才有效。

## 执行指定

以下三名船员中必须有两人批准：

- 治安法官。
- 舰长或代理舰长。
- 安保主管或代理安保主管。

红色或更高级别警报期间，安保主管可以依自身权限口头指定公司之敌，但危机结束后仍须补齐文件。

应尽快通过传真等方式向中央指挥部报告所有公司之敌指定。

被指定后，公司之敌必须被永久关押在安保区直至撤离，并剥夺所有船员相关装备与身份证明。

如果公司之敌成功逃脱关押，其身份将变为实际战斗人员，应按敌对登船者处理。

错误地把某人指定为公司之敌，可以作为立即解雇的依据。
