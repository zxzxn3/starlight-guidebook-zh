# 指挥层澄清

1. 人事主管是空间站舰长的第二继承人，但其职级与其他所有部门主管相同。
2. 人事主管可以在相关部门主管同意后雇用或解雇职员。
3. 人事主管不能向服务部以外的任何部门下达命令，也不能从这些部门调动人员。
4. 监狱长被视为安保部门的二把手，但不属于指挥层。
5. 助理指挥归人事主管管理，但不属于服务部。
