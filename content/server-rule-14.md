# 规则 14：连续性准则

Starlight 会在限定范围内，让部分信息、连续性和记忆跨越回合保留。世界观内，这由 PSO 克隆系统实现；为保证角色扮演顺畅并减少干扰，该系统也有限制和规则。

角色只能记得自己幸存的班次。如果角色被困或死亡，就会完全忘记该班次。如果尸体抵达中央指挥部时仍可复活，角色也会记得该班次，但按照规则 3，会忘记导致死亡前的一切细节。进入低温休眠舱可以让角色保留进入休眠舱前的记忆。

**任何受[元信息屏障](metashield.html)保护的信息**都会在班次之间被遗忘，并从克隆体的记忆中清除。例如，一名在革命中幸存下来的舰长仍会忘记关于革命的信息，不记得该班次发生过革命。

角色可以记得发生过犯罪，但永远不记得罪犯是谁，即使自己曾是辛迪加特工也一样。

**可以**记得的内容示例：

- 与另一名角色的社交互动，例如一起在酒吧喝酒，甚至发生过争执。
- 角色通常从事什么岗位。不过，如果某人没有做平常的工作，也不能利用这一点产生“一定出事了”的元知识。
- 空间站布局。可以适当允许角色忘记秘密房间；出于 OOC 原因，维修通道看起来每个班次都一样，但世界内始终像不断变化的迷宫。

**不能**记得的内容示例：

- 植物学家 Joe 是偷走舰长喷气背包的辛迪加成员。
- 核特工攻击空间站。
- 中央指挥部启动 Epsilon 警戒并杀死空间站上的大量人员。
- 目击空心尸体，或看到变形者吃人。
- 作为 NanoTrasen 代表，记得上个班次出现过核特工。
