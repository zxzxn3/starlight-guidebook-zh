# 规则 1：尊重管理员决定

管理员帮助（Ahelp）用于联系管理员处理干预、规则解释或破坏游戏的漏洞。所有漏洞都应通过游戏内漏洞报告或 Discord 报告。

Ahelp 不用于发泄、投诉、请求成为敌对角色或评论当前回合。

无视管理员消息、在 Ahelp 期间断线以逃避回应、侮辱管理员或说谎，都可能带来后果。

这些规则用于说明服务器对玩家的游玩预期。它们是准则，无法覆盖所有具体情况。最重要的是：管理员要求你停止某件事时，就停止。

你可以解释自己的观点和理由，但即使不同意，也必须遵守管理员的要求。如果你认为处罚、裁定或其他管理操作有误或不公正，请通过 Discord 工单申诉。

如果你想做某件事，但不确定规则是否允许，请先通过 Ahelp 询问。

也请记住，管理员并非全知全能，也无法同时出现在所有地方。他们有很多工具可以阻止违规者，但通常无法在事件发生前阻止一切。

请使用 Ahelp（<kbd>F1</kbd>）报告违规行为。即使只是直觉上的疑虑，也可以请求管理员调查。

违反本规则的示例：

- “规则里又没写我不能这么做！”
- “其他玩家都没意见！”
- “上次也没人有意见！”
