# 规则 2：禁止恶意破坏、滥用漏洞和利用机制

禁止故意破坏其他玩家的游戏体验。以下可能导致回合结束或造成严重干扰的行为尤其禁止：

- 故意释放 Tesla 或 Singularity，或让 Supermatter 失控。
- 进行部门规模或更大规模的空间站破坏。
- 故意通过空间站空气分配网络灌入危险气体，例如等离子、氚、Frezon、Zauker，或任何被加热或冷却到不适合生存程度的气体。

这些行为可能导致永久封禁。某些目标或情况可能允许例外；有疑问时，请先询问管理员。

通过音频表情、门禁失败音效或聊天内容刷屏，造成 TTS 过载，也属于违规。这包括代理刷屏，例如命令“所有赛博格在全站频道报出法则”。

最后，禁止滥用漏洞、利用机制或明显非预期效果取得不公平优势。请通过游戏内漏洞报告或 Discord 报告问题。

## 挂机收益与刷敌对角色

- 禁止为满足岗位游玩时长要求而挂机；玩家必须主动参与并为游戏作出贡献。
- 因为没拿到敌对角色而变成幽灵、自杀或以其他方式离开游戏，属于“刷敌对角色”（Antag Rolling），不允许。
- 为了接管回合中出现的敌对角色幽灵槽位而变成幽灵、自杀或以其他方式离开当前角色，也属于“刷敌对角色”，不允许。
