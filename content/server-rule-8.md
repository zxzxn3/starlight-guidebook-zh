# 规则 8：禁止猎杀敌对角色（No Validhunting）

非安保人员不应自行阻止或追捕敌对角色。这不符合角色对自身职责的合理认知。安保人员和 ERT 负责保护空间站；在条件允许时，应通知他们处理。

“蓝盾”（Blue Shield）安保**不属于**普通安保人员，不得为了追逐潜在威胁而离开保护对象。

生死关头、核特工等全站威胁和自卫可以构成例外。

人工智能（AI）不得主动猎杀敌对角色或立即尝试将其关闭，除非法则允许，或已经检测到船员正在受到直接伤害。AI 的行为应是被动响应，而非主动搜索威胁。

指挥人员不应在没有必要时促成猎杀敌对角色；遇到这类情况应询问安保。

**猎杀敌对角色的示例：**

- 打捞专家购买枪械并登站消灭叛徒、变形者或吸血鬼，却没有接到指挥部的命令。
- 蓝盾为了追捕敌对角色而穿过维修通道，把指挥人员或 NanoTrasen 员工留在无人保护的状态。
- 蓝盾追着并未伤害任何指挥人员的巫师进入太空。
- 安保人员齐备且足以处理情况时，研究主任命令科学家追捕刚杀死人事主管的叛徒。
- 助手追进维修通道，寻找十分钟前看到其攻击他人的叛徒。
- 助手追进维修通道，寻找看到其穿着辛迪加违禁品的叛徒。

**遵守本规则的示例：**

- 打捞专家只有在被请求协助后，才登站处理全站威胁。
- 蓝盾保护指挥人员或 NanoTrasen 员工免受敌对角色伤害，直到对方撤退或被击至濒死。
- 蓝盾追入太空，因为巫师偷走了指挥人员的身体并带回自己的飞船。
- 助手通过无线电报告看到有人穿着违禁品。
- 助手保护自己或他人免受攻击，直到攻击者撤退或被击至濒死。
