# 规则 13：领导岗位的期望

担任指挥部、NanoTrasen 直属员工、打捞队长和安保等领导岗位的玩家，适用更高的角色扮演标准，应表现得专业且负责。这些员工必须遵守所属岗位的标准作业程序（SOP），维护岗位应有的职责。

滥用领导岗位或白名单岗位可能导致岗位封禁；反复违反可能导致服务器封禁，或永久禁止担任所有此类岗位。

地方法官（Magistrate）和 NanoTrasen 代表尤其应诚信履职。故意违反 SOP、滥用职权或欺骗中央指挥部，可能导致永久禁止担任这些岗位。

## 对领导、安保与白名单玩家的期望

- 所有成员必须遵守所属岗位的 SOP，确保领导公平并正确管理部门。
- 指挥人员不得滥用通讯控制台发布不专业的公告。
- 安保岗位必须尽力遵守 SOP，正确执行企业法，公平对待罪犯，并让玩家获得良好体验。
- 白名单岗位必须遵守 SOP，维护专业岗位的完整性，并展现良好的角色扮演能力。
- 应始终穿着得体；指挥部、安保和白名单岗位应穿着符合身份的服装。

## 可处罚行为示例

- 人事主管无必要地授予全区域通行权限，违反 SOP。
- 部门主管过度滥用职权，虐待下属或无视 SOP 职责。
- 监狱长对首次犯罪且配合调查的罪犯判处最高刑期。
- 完全无视 SOP，从事岗位职责之外的行动。
- 一般性 LRP 行为，或违反规则 3 的 MRP 逻辑。

## 学员例外

- 安保学员仍在学习，因此不受本条岗位经验期望约束。
