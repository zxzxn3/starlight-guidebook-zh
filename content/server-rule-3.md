# 规则 3：遵守中角色扮演标准

Starlight 是一个中角色扮演（Medium Roleplay, MRP）项目。玩家应充分代入角色并按其身份行动。每个举动都应符合一个真实的人在该岗位上合理的表现。**游玩本回合的目的不是“赢下游戏”**，而是与其他玩家共同展开角色扮演。

角色应当畏惧死亡，并谨慎权衡行动。玩家可以记住角色以及不同回合之间模糊的互动，但受[元信息屏障](metashield.html)保护的信息不得被记住，例如核特工的存在。

## 玩法违规

- **强度向玩法（Powergaming）**：为尚未发生的情况过度准备，例如舰长提前把自己的舱室焊死，或收集与岗位职责无关、但能带来显著优势的装备。也包括在角色扮演中优先采用“为赢而玩”的策略，例如诱导目标开始打字，使其在遭到攻击时无法自卫。
- **元游戏（Metagaming）**：利用游戏模式、规则触发时间等“元知识”，利用只为玩家操作方便而存在、角色世界中没有解释的机制，利用作为幽灵观察时看到的事件，或利用尚未通过角色本回合经历得知的受屏障信息来取得优势。
- **混淆 IC 与 OOC 聊天**：不得在 IC 中讨论 OOC 概念，例如在无线电里谈论“管理员”。除了澄清玩家之间的互动，也不得在 OOC 聊天中争论角色的感受或行动。不得在 LOOC 中讨论当前回合的游戏模式或敌对角色。
- **网络缩写、梗与脑腐表达**：IC 对话不得使用“u r so lame fr fr”之类语言缩写，也不得使用“6 7”“skibidi”等非 SS14 网络梗。

## 行为与角色扮演规范

- **自残或自杀**：只有在极少见、且没有其他逃脱办法的情况下才允许，不应将其当作轻松或随意的话题。执行前请通过 Ahelp 说明情况并请求许可。
- **失去意识后的失忆**：因强制睡眠、吸血鬼催眠、重伤、死亡或硅基生命被弹出底盘而失去意识时，应忘记相关事件。详情见元信息屏障的“无意识信息”一节。
- 被精神控制的角色，例如革命者、邪教徒或被奴役者，在解除控制后会忘记被洗脑期间发生的事。
- **假定具备岗位能力**：角色的行动应符合其岗位应有的专业能力，不做不现实的举动。与船员同一阵营的大气技术员不会把一氧化二氮灌入配气网络来“恶作剧”；与船员同一阵营的化学家不会大规模分发违禁化学品；与船员同一阵营的厨师不会屠宰船员尸体并端上餐桌。角色也不应长期玩忽职守，例如一直在酒吧喝酒、无视紧急请求，或整班次只顾与伴侣约会。
