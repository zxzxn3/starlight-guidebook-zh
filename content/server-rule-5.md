# 规则 5：敌对角色必须遵守 MRP 逻辑

敌对角色只应采取能直接推进自身目标的敌对行动。否则可能被视为违反 MRP 逻辑并受到处罚。

团队敌对角色**必须**与队友合作，并在可能时服从领导者，例如革命者、恐怖蜘蛛等。

在面对指定任务目标之外的对象时，敌对角色必须遵守武力升级规则。如果目标包括“活着且未受束缚地逃离至中央指挥部”或类似内容，敌对角色应**尝试**在整个班次中保持隐蔽。

如果敌对角色因意外或被另一名敌对角色供出而暴露，就不必继续隐藏；但不能借此进行大规模 RDM 或违反其他服务器规则。传统潜行型敌对角色“转入公开行动”并不意味着可以猎杀所有安保，而是可以公开自卫。

以下敌对角色可以从回合开始就公开行动，不必逐级升级武力。这些角色也不得偏离目标去屠杀全站，而应围绕目标行动：

- [太空龙](MinorAntagonists)
- [Eeep（Electric Sheep）与 Eeeplet](Eeeps)
- [熵之巨像](CosmicColossus)
- [核特工与独行特工](NuclearOperatives)
- [巫师](Wizard)
- [鼠王](MinorAntagonists)
- 在积蓄足够力量、准备推翻空间站后转入公开行动的转化型敌对角色，例如[革命者](Revolutionaries)、[异形赛博格](Xenoborgs)和[邪教徒](CosmicCult)

敌对角色不得采取直接违背其核心机制或目标的行动。例如，太空龙不应故意点燃等离子或氚火；巫师不应全力隐藏自己；没有“死也要拉一个”目标的叛徒不得与核特工或独行特工结盟。

禁止炸毁、撞击或以其他方式大规模破坏撤离穿梭机。不过，敌对角色可以在穿梭机起飞前尝试完成任务。回合结算界面出现后，所有敌对行动必须停止，敌对角色应尝试逃离或混入船员。

如果核弹磁盘位于穿梭机上，核特工和独行特工可以获得例外。

## 僵尸

初始感染者只要遵守全部服务器规则，就可以破坏空间站。但一旦你成为僵尸，就只能为接近自己能看到或听到的活体生物而进行破坏。

- 不得攻击灯具、电力设施、大气管道或设备。
- 赛博格不是有效目标，除非其正在攻击你，或把食物从你身边拖走。
