# 规则 7：禁止自我敌对

自我敌对是指任何针对空间站或船员的故意恶意行为。有些情况也属于规则 3 的范围，此外还包括：

- 随机攻击船员，在没有角色扮演理由的情况下殴打或杀死未敌对船员。
- 无故骚扰安保，持续干扰逮捕，或在角色没有 IC 动机时攻击、阻碍安保人员。
- 在没有角色扮演理由的情况下盗窃关键或独特物品，包括同事的 ID 和敌对角色的盗窃目标。
- 无必要地破坏空间站，例如切断关键电力线路、把气闸舱排向太空，或在没有角色扮演理由时毁坏重要设备。
- 主动帮助敌对角色，例如向已确认的敌人交出武器、为船员破坏逃生路线，或在没有角色扮演胁迫的情况下藏匿已知威胁。

本规则不禁止非敌对角色违反企业法。作为自愿参与空间站工作的员工，角色应作出相应行为，但胁迫、威胁或生死关头等角色扮演因素可以为某些行动提供理由。

**合理的 IC 企业法违规示例：**

- 在空间站面临严重全站威胁时，打开武器箱自卫。
- 因激烈的 IC 争执或个人恩怨，进行非致命斗殴。
- 在空间站大部分区域被毁或门禁失效时，黑开门前往安全区域或关键系统。
- 长时间等待门禁许可后，为了完成必要的岗位工作而非法闯入。
- 面对正在进行中的威胁时，即使技术上违反袭击法，也为自己或他人进行身体自卫。
- 在紧急情况下没有正常门禁时，从仓库取走医疗设备或工具。
- 接受一大笔贿赂，对某项行动或情况视而不见。这通常会带来 IC 后果。
