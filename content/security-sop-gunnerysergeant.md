## §2 安保警务部门负责人

1. 枪炮军士负责组织并协调安保的日常警务工作，包括但不限于：
   - 1.1 **巡逻**：确保空间站各处有足够安保力量。
   - 1.2 **调查**：确保已报告的犯罪得到及时跟进。
   - 1.3 **执法**：确保罪犯按照 SOP 和企业法被迅速处理。
2. 枪炮军士负责组织、装备并带领小队对抗空间站上的敌对人员。
3. 枪炮军士负责训练和分配安保学员。
4. 安保主管缺席时，枪炮军士负责接管安保部。
5. 枪炮军士的量刑权限与安保官相同。

## §3 安保军需管理

1. 枪炮军士负责确保安保官的装备水平与威胁等级相符。
   - 1.1 为此，枪炮军士有权在蓝色警报期间提交并批准发放军械库装备的许可证。
   - 1.2 红色警报期间，枪炮军士可以自由发放军械库装备。
2. 枪炮军士负责确保按照警报 SOP 的规定开放军械库。
3. 枪炮军士负责确保警报升级期间借出的装备最终归还军械库。
4. 枪炮军士负责利用自己的军械库权限，正确储存安保官查获的违禁品。
