# 许可证示例

| **工程护目镜** - **来自工程部：**如果护目镜来自工程部，只需总工程师盖章。- **从 ITG 购买：**如果从 ITG 购买，则同时需要打捞负责人和总工程师盖章。 |
| --- |
| **Mk 58** - **来自安保部：**如果 Mk 58 来自安保部，只需监狱长或枪炮军士其中一人盖章。- **从 ITG 购买：**如果从 ITG 购买，则同时需要打捞负责人，以及监狱长或枪炮军士其中一人盖章。 |
| **医疗生命救助器** - **无来源，例如在维护区找到：**由于没有部门来源，而且医疗部与安保部都获准使用，只需以下任意一名相关部门负责人盖章：首席医疗官、监狱长、枪炮军士或安保主管。 |
| **绿色拾荒者贝雷帽** - 该物品未在 NT-CC 任何部门获准使用，因此只需打捞负责人盖章。 |
| **猫耳** - 作为 1 级竞争公司物品，只需监狱长或枪炮军士其中一人盖章。 |
| **CODE-4“分诊”** - 作为 4 级关联公司武器，需要 MedTak、安保主管和舰长盖章。 |
| **血红色硬质宇航服** - 本项仅限拥有安全知识的船员查看。- 作为 4 级竞争公司战斗装备，需要安保主管、舰长和中央指挥部盖章。 |
