# 安保

除个别岗位 SOP 另有规定外，以下程序适用于所有安保成员。

## §1 安保的职责

1. 安保的首要目标是保护空间站及其资产，船员也属于空间站资产。
2. 其次，安保是指挥层与中央指挥部的执法力量；船员的上级提出要求时，由安保处理不服从的船员。
3. 执行上述职责时，安保受[企业法](corporatelaw.html)的限制与约束，同时也是空间站上企业法的主要执行者。

## §2 制服要求

1. 安保成员必须始终穿着可见的正式安保制服或连体服。
   - 1.1 执行特定任务确有必要时，配发护甲可以遮住制服，例如舱外活动时穿着的硬质宇航服。
   - 1.2 安保主管可以为例行调查批准例外。
2. 如果安保主管认为个人饰品或非规定服装损害了安保部的专业形象，可以随时要求安保成员移除。
3. 安保成员应始终将宇航服传感器设置为坐标模式。

## §3 武器与战斗装备

1. 除非其他程序另有规定，安保最多只能携带其“标准绿色警报装备”所列物品。
2. 除非装备正在使用，否则不得公开携带上述装备。

## §4 武力使用

1. 使用任何武力前，必须先向被捕者说明逮捕理由。
   - 1.1 已知持有武器且具有危险性嫌疑人不受此限制。
   - 1.2 嫌疑人在说明前试图逃跑时不受此限制。
2. 执法过程中必须避免对空间站船员造成不必要伤害，以免损害空间站的任务。
   - 2.1 因此，必须给嫌疑人自行步行前往安保部的机会，不得使用束缚或武力。
   - 2.2 如果嫌疑人拒绝配合，可以使用禁用武器和束缚装置将其制服，同时尽量避免损害其工作能力。
   - 2.3 已知持有武器且具有危险性的嫌疑人不适用上述规定。
3. 除了正在追捕逃跑嫌疑人，禁止强行进入其他部门。
   - 3.1 如有必要，安保可以向相关部门申请搜查令。

## §5 搜查与扣押

1. 没有正当理由时，安保不得搜查或突袭船员及部门。正当理由包括：
   - 1.1 亲眼看到船员使用违禁品，并立即把物品藏到身上。
   - 1.2 已获批准并正确提交的搜查令。
   - 1.3 紧急状态，或蓝色及以上警报。
2. 拒绝 §5.1 所列合法搜查的船员可以被扣留，并对其强制执行搜查。
3. 搜查中发现或平时发现的违禁品，必须送往军械库封存作为证据。
   - 3.1 因暴力犯罪被判刑的嫌疑人，即使某项装备是岗位必需品，也可以没收其任何暴力工具。
   - 3.2 因非法侵入或破坏设备被判刑的嫌疑人，即使某项工具是岗位必需品，也可以没收其实施该类犯罪所需的工具。

## §6 紧急状态

1. 如果当前警报等级的相关程序与本 SOP 冲突，以警报程序为准。
2. 同一色系的安保警报会继承较低等级的规则，除非较高等级覆盖该规则：
   - 2.1 红色 → 伽马 → 德尔塔
   - 2.2 黄色 → 橙色
3. 红色和紫色警报期间，安保可以不遵守 §2、§3 和 §4，按需要或部门主管要求进行装备并行动。
4. 黄色、红色或紫色警报期间，为安全处理相关威胁，安保可以强制转移船员。
