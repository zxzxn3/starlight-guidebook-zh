# 假释

1. 为保证各部门持续运作，条件合理时，鼓励安保给予假释。
   - 1.1 假释可以由审判结果决定，也可以由监狱长或安保主管酌情批准。
2. 获得假释的囚犯应离开安保部，并在犯罪记录系统中标记为“Paroled”。
3. 监狱长或安保主管可以要求假释人员在假释期间定期到安保部报到。
   - 3.1 超过 5 分钟仍未报到，将被视为违反监管。
   - 3.2 报到频率不得高于每 15 分钟一次。
   - 3.3 假释人员随时可以被安保搜查。
4. 刑期结束后，假释人员可以返回安保部领取临时没收的装备，例如工具。
