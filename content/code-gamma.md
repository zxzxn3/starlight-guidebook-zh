# 伽马警报

## 发布权限

中央指挥部。请使用通信控制台或传真机说明情况。伽马警报很少发布，这是有原因的。写一封简洁、清楚、署明舰长或代理舰长姓名并盖章的传真，尽可能说明现状以及为什么需要伽马警报，会大大提高获准概率。请记住，这只适用于极端紧急情况。

## 条件

空间站和船员面临生存级威胁；如果没有中央指挥部介入，空间站很可能会失守。

不过，威胁尚未严重到必然导致空间站被摧毁。

## 安保

1. 实施戒严，标准作业程序与太空法暂停执行。安保人员有权采取一切必要行动拯救空间站。妨碍应急程序的人员可以被扣留；面对任何实际人身威胁时，安保可以使用致命武力。袭击指挥层、紧急响应小组或安保人员，可能被立即就地处决。
2. 完全允许并鼓励随机搜查。拒绝搜查的人员可以被安保扣留，以便完成搜查。
3. 应开放军械库，由安保保护其中物资并分发给安保人员，以应对威胁。未经典狱长、安保主管或舰长批准，非安保人员，包括法律子部门成员，不得领取军械库武器。
4. 安保人员应全面配合中央指挥部人员，例如紧急响应小组，以消除空间站面临的威胁。

## 安全区域

1. 安全区域仅限指挥层、安保和中央指挥部人员进入。
2. 安全区域包括：安保部、EVA 储藏室、技术储藏室、重力发生器、工程部大厅以外的所有区域、金库，以及需要指挥权限的区域。
3. 应锁闭安全区域，但指挥层可以下令保持开启。

## 医疗

建议将医疗入口设置为紧急通行，以便人员自行接受治疗。

## 普通船员

1. 所有人员都应将宇航服传感器设置为坐标模式。
2. 除非中央指挥部人员、安保或指挥层特别要求，人员必须留在本部门或最近的安全区域。
3. 拥有特别有用技能的人员可以例外，例如工程、大气或医疗人员。
4. 来访者应留在酒吧、图书馆或宿舍内。
5. 只要安保人员的命令符合太空法，且不会损害空间站及船员的整体利益，人员就应服从。否则可能因制造工作场所危险而被逮捕。
