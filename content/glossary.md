# 术语表

本页收录空间站和社区中常见的简称与俚语。

# IC 俚语

这些词会在游戏内出现。

- **AOS**：Arrest on Sight，发现即逮捕。
- **AA**：All Access，拥有全站权限的 ID。正常情况下只有舰长拥有。
- **Atmos**：Atmospherics，大气系统。
- **Atmosian**：大气技术员，或非常熟悉大气系统的人。
- **Bolted**：气闸永久锁定在开门或关门状态，红灯常亮。
- **Borg**：Cyborg，赛博格。
- **Braindead**：玩家断线，角色暂时无反应，但之后仍可能重连。
- **Brig**：安保部门监狱区，由监狱长管理。
- **Cap**：Captain，舰长。
- **Cargonia**：货运宣布独立，违规行为。
- **CE**：Chief Engineer，总工程师。
- **CentComm / Central Command**：监督空间站的中央指挥部。
- **CL**：Corporate Law，企业法。
- **CMO**：Chief Medical Officer，首席医疗官。
- **Crit / Critical**：濒死状态，失去意识和移动能力，需要救助。
- **Emag**：辛迪加加密序列器；也指被其破解的门或设备。
- **EA / Emergency Access**：紧急通行，任何人都能开门，黄灯闪烁。
- **ERT**：Emergency Response Team，紧急响应小队。
- **Flukie**：失败任务的核特工，带贬义。
- **God(s)**：IC 中对服务器管理员的称呼，也可用 CentComm。
- **Greytide / Greyshirt / Tider / Assistant**：助手；也可贬称扰乱秩序、犯轻罪的船员。
- **HoP**：Head of Personnel，人事主管，也可指其办公室。
- **HoS**：Head of Security，安保主管。
- **Insuls**：Insulated Gloves，绝缘手套。
- **Jani**：Janitor，清洁工。
- **KOS**：Kill on Sight，发现即杀。
- **Mats**：Materials，材料，通常指钢、塑料、塑钢、玻璃、银和金。
- **NT / NanoTrasen**：拥有空间站的公司。
- **Newkie**：经验不足的核特工。
- **Nukie / Nuke Op**：Nuclear Operative，核特工。
- **Perma**：Permanent Brig，永久监禁。
- **QM**：Quartermaster，货运主管。
- **RD**：Research Director，研究主任。
- **Robust**：擅长战斗或能在苦战中存活。
- **Salv**：Salvage，打捞。
- **Sci**：Science，科研部。
- **Sec**：Security，安保部。
- **Secoff**：Security Officer，安保官。
- **Shift**：班次，即一回合。
- **Singulo**：单数引擎。
- **Singuloose**：单数体脱困并破坏空间站。
- **SOP**：Standard Operating Procedures，标准作业程序。
- **Spacing**：失压或船体破洞。
- **Spess**：对 Space 的故意拼错，也可指太空混乱。
- **SSD**：Space/Sudden Sleep Disorder，玩家断线后的 IC 解释。
- **Syndie / Syndi / Syndicate**：辛迪加及其成员。
- **TC**：Telecrystal，传送晶体。
- **Wardenloose**：监狱长离开监狱区的玩笑说法。
- **Xenoarchaeology**：异星考古。

# OOC 俚语

- **Admeme**：管理员举办或制造的事件。
- **AHelp / Admin Help**：向管理员报告问题。
- **Antag**：Antagonist，敌对角色。
- **Bwoink**：收到 Ahelp 时的提示音。
- **Ick Ock**：在 OOC 中泄露当前回合 IC 信息。
- **LOOC / OOC**：本地 OOC 与全局 OOC。
- **LRP**：Low Roleplay，低角色扮演。
- **MRP**：Medium Roleplay，中角色扮演。
- **HRP**：High Roleplay，高角色扮演。
- **Self-Antag**：不是敌对角色却从事敌对行为，违规。
- **Upstream**：游戏上游基础版本，Wizard's Den 官方服务器使用此版本。
- **Validhunter**：非安保玩家主动猎杀“可击杀目标”。
