# 紫色警报

## 发布权限

任意两名指挥层成员或舰长。

## 条件

病毒病原体已感染相当一部分船员。发生病毒爆发时，所有感染者必须立即前往医疗部。

## 安保

1. 应尽快保护医疗部，隔离感染者是首要任务。
2. 如果无法保护医疗部，应保护撤离穿梭机的抵达区域。

## 安全区域

1. 除非岗位职责需要，进入安全区域必须取得通行许可。
2. 安全区域包括：医疗部、安保部、EVA 储藏室、技术储藏室、重力发生器、工程部大厅以外的所有区域、金库，以及需要指挥权限的区域。
3. 锁闭安全区域不受限制。是否锁闭由指挥层成员决定。
4. 非指挥层成员不得进入安全区域，除非岗位职责需要。

## 医疗

1. 化学部必须立即开始研究治疗方法。
2. 应封锁医疗入口，防止医疗人员进一步感染。应以受控方式允许船员进入医疗部。
3. 隔离所有可能感染者。
4. 已失去行动能力的感染者应送往化学部，协助生产治疗药物。
5. 治疗药物研制完成后，应分发给船员。

## 普通船员

1. 人员应自我隔离，避免感染。留在安全区域，远离可能感染者。
2. 如果怀疑自己感染，应冷静等待医疗部分发治疗药物。
3. 威胁解除后，可以恢复工作。

## 指挥

如果空间站威胁过高，无法继续处理，应呼叫紧急撤离穿梭机。
