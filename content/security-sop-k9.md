2. 安保主管或监狱长可以指派一名安保成员担任 K9 的训导员。
   - 2.1 如果没有指派训导员，K9 必须始终跟随并服从一名正式安保成员。
   - 2.2 发现 K9 无人陪同游荡时，应为其指派训导员，最好由监狱长或安保主管指派。
3. K9 必须遵守[安保 SOP §4](security-sop-intro.html)的标准升级原则，并服从训导员或其他安保成员对局势的处理方式。K9 不得敌视配合的嫌疑人，也不得对船员或犯罪嫌疑人表现出公开敌意。
   - 3.1 这包括不违抗命令，不对船员、嫌疑人和囚犯造成不必要伤害，不破坏财产，以及无理由逃离训导员或其他安保成员。
   - 3.2 K9 的咬击被视为较低致命性的武力。没有正当理由时，K9 不得咬人。
   - 3.3 只有在训导员或其他安保成员在场并参与追捕时，K9 才能扑咬嫌疑人。
   - 3.4 如果因训导员倒地等特殊情况无人陪同，或局势发展过快、无法等待安保，K9 可以自行作出最佳判断。
4. K9 必须接受训导员的训练和命令；训导员还负责报告并惩罚 K9 的不当行为。训导员不在时，任何安保成员都可以履行该职责。
   - 4.1 惩罚必须与不当行为相称，不得造成直接身体伤害。
5. 如有必要，安保主管可以签署文件将 K9 降职，或在确有必要时批准安乐死。
6. K9 不受[安保 SOP §2](security-sop-intro.html)的制服要求约束。
