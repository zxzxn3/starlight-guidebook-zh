# Sawian

<entity id="GuideExpie"></entity>

Sawian 是基于多种地球基因组人工创造的种族，经常在 NanoTrasen 空间站工作。他们在生物学上没有性别，但部分个体仍有男性化或女性化外观。

Sawian 不习惯穿衣。穿着越少，移动越快：头部、外套、面罩、鞋、内衬和手套全部为空时速度为基准的 125%；所有槽位穿满后降至 95%。

## 生命值

Sawian 非常耐久，被设计为能在多数种族致命的环境中生存。

- 多数个体有脑植入体，可以详细读取身体状况。
- 耐久使其能在濒死状态维持一段时间。受到 100 点伤害时进入“软濒死”，仍可爬行、说话和使用物品，但会持续受到窒息伤害；150 点伤害昏迷，200 点伤害死亡。
- 代谢较快，处理药物和毒素更快。
- 饥饿和口渴速度是人类的 3 倍；未挨饿时拥有额外恢复效果，非濒死状态下被动治疗速度约为基础的两倍。
- 挨饿时每秒受到 0.5 点腐蚀伤害，直到死亡。

## 一致性

- 同一种族的个体在性格和基因组成上很少偏离标准，差异通常来自饰品、伤疤或配件。
- 转移到 CC 前，所有 Sawian 都会获得四位数字 ID 和一个昵称，例如 `#4466 John`、`#7201 Jimmy`、`#1793 Jane`。CC-NT 保留了该系统，便于转入雇佣体系。

NT 要求 Sawian 清理不合适的 ID。极低数字或暗示性数字，例如 `#6969`、`#6767`、`#0420`、`#8008`，必须更换，绝不能带到空间站。
