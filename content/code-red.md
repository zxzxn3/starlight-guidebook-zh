# 红色警报

## 发布权限

任意两名指挥层成员或舰长。

## 条件

空间站上或附近太空区域存在已确认的敌对威胁，并对空间站或全体船员构成明确、实际的危险。

## 安保

1. 完全允许并鼓励随机搜查。拒绝搜查的人员可以被安保扣留，以便完成搜查。
2. 安保人员应全面配合中央指挥部人员，例如紧急响应小组，以消除空间站面临的威胁。
3. 安保 SOP 将规定武器、军械库和安全操作流程。

## 安全区域

1. 除非岗位职责需要，进入安全区域必须取得通行许可。
2. 安全区域包括：安保部、EVA 储藏室、技术储藏室、重力发生器、工程部大厅以外的所有区域、金库，以及需要指挥权限的区域。
3. 锁闭安全区域不受限制。是否锁闭由指挥层成员决定。
4. 非指挥层成员不得进入安全区域，除非岗位职责需要。

## 医疗

建议将医疗入口设置为紧急通行，以便船员在紧急情况下自行接受治疗。

## 普通船员

1. 只要安保人员的命令符合太空法，且不会损害空间站及船员的整体利益，人员就应服从。
2. 建议人员就地避难，并遵守安保命令。
3. 在特殊情况下或人员反复不服从时，舰长可以决定对拒绝服从安保命令者使用致命武力。

## 战争状态宣告

1. 所有武器限制解除。
2. 货运部应尽可能订购更多武器。优先分发给安保，但普通人员也可以武装。
3. 科研部必须尽快开展研究，没有商量余地。科研部应与货运部协作，制造保卫空间站所需的武器与装备。
4. 建议设置路障、玻璃和陷阱来对抗威胁。
5. 指挥层可以决定呼叫撤离穿梭机。如果战斗结束后空间站没有损坏，建议船员完成本班次。
