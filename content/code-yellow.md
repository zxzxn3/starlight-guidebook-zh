# 黄色警报

## 发布权限

任何指挥层成员。

## 条件

空间站面临中等程度的大气或结构威胁，需要工程部集中处理。

## 安保

1. 封锁危险区域。
2. 查明空间站受损原因。
3. 阻止非工程人员进入受损区域。
4. 防止空间站遭受进一步破坏。

## 安全区域

1. 除非岗位职责需要，进入安全区域必须取得通行许可。
2. 安全区域包括：安保部、EVA 储藏室、技术储藏室、重力发生器、工程部大厅以外的所有区域、金库，以及需要指挥权限的区域。
3. 锁闭安全区域不受限制。是否锁闭由指挥层成员决定。
4. 非指挥层成员不得进入安全区域，除非岗位职责需要。

## 医疗

1. 医疗人员应准备好救治灾难伤员。
2. 护理人员应与事故现场人员协作，对伤员进行分诊。

## 工程

1. 立即与总工程师协调，确认空间站受损程度。
2. 与工程部和安保合作，封锁并调查事故区域。
3. 首先尽快恢复区域安全；确认安全后再进行进一步维修。

## 普通船员

1. 避开受损区域。
2. 发现可疑活动时，向受损区域的安保人员报告。

## 特殊情况

### 大规模火灾与有毒气体泄漏

1. 所有非工程、非大气人员必须撤离相关区域。
2. 防火门系统只能由工程与大气人员操作。在火灾或有毒气体泄漏期间故意打开受影响区域的防火门，将被视为破坏财产或大规模破坏。
3. 工程与大气人员应把受影响区域恢复到可工作状态。

### 严重流星风暴

1. 人员应前往空间站防护最强的区域避难。
2. 风暴结束前应暂停一切维修活动。
3. 所有执行 EVA 任务的人员必须立即返回空间站。
4. 风暴结束后，工程人员应在可行时修复空间站。
