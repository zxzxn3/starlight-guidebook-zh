# 规则 4：武力升级必须合理

战斗应遵循合乎逻辑的升级过程，禁止无理由攻击或杀死其他船员，也就是 RDM。安保人员在处理囚犯和不同警戒等级下的船员时，必须遵守标准作业程序（SOP）。

玩家互动应体现现实的冲突升级。轻微争执可能发展为肢体冲突，但非敌对角色很少应升级到杀人。非敌对角色的武力升级通常应遵循以下顺序：**言语交涉 > 非致命武力 > 致命武力**。鼓励敌对角色围绕目标展开角色扮演，以增强代入感和故事性。

行动应从轻开始，每名船员在遭到攻击时都保留自卫权。这也包括敌对角色躲避或反抗安保。非敌对角色不应严重伤害安保人员，除非确有必要。

除非目标是敌对角色指定的任务目标，否则明确禁止 round removal，包括绞碎、丢入深空、藏进关闭坐标追踪的储物柜，或对尸体造成过度破坏。

**合理升级示例：**

- 因为小丑滑倒你而推他一下。
- 因为被推了一次，与对方互殴并发展成拳斗。
- 安保试图逮捕你之后，你殴打或击晕该安保。
- 作为厨师，反复要求某人离开厨房、尝试将其拖走，但对方仍拒绝离开或弄乱、偷东西时，用刀刺伤对方，直到其离开。
- 作为安保，当对方试图用 Disabler 或警棍击晕你时，改用致命武器射击。
- 作为安保，当对方拿出致命武器或枪械并表现出伤害意图时，改用致命武器射击。
- 作为指挥人员，反复要求非法闯入者离开后，用闪光弹驱赶。

**不合理升级示例：**

- 因为小丑滑倒你一次，就把他打到濒死。
- 因为被推了一次，就用刀刺到对方濒死。
- 因为安保试图逮捕你，就使用致命武器射击安保。
- 作为厨师，因为需要肉或对方拒绝离开厨房，就把人刺死并挂上肉钩屠宰。
- 作为安保，因为对方打了你一拳或仅仅拒绝命令，就使用致命武器射击。
- 作为指挥人员，反复要求对方离开后，直接开枪。
