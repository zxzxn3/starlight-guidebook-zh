# 律师

<entity id="ToyFigurineLawyer" caption="Lawyer"></entity>

1. 律师直接向人事主管报告。
2. 接到审判传唤时，律师必须出庭，并应为客户提供法律建议，以及执行分配的其他职责。
3. 仲裁中央指挥部雇用人员之间的轻微纠纷时，律师应保持公正，并对所有相关方提供公平调解。
4. 除非安保或指挥层成员要求，律师不应介入囚犯在认罪协商以外的法律事务，并应把这些事务交给内务部探员处理。
5. 人事主管保留立即解雇律师的权利，无需理由或解雇表。
