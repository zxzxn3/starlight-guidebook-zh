Reagent Flow

Understanding how reagents move through plumbing networks is key to building efficient factories.

Networks

A plumbing network is a group of machines and ducts connected together through their connectors. Reagents can only flow between machines on the same network.

Plumbing ducts support three layers (Primary, Secondary, Tertiary). Ducts only connect to other ducts/nodes on the same layer unless a bridging component (such as a manifold) links paths.

Each inlet connector on a machine forms its own independent network. This means if a machine has multiple inlet connectors, each one connects to a separate network. Pipes attached to different inlets on the same machine do not bridge.

Outlet connectors on the other hand can be connected and bridge networks. Most machines bridge outlets into one network, but some (currently only the plumbing buffer) intentionally keep outlets isolated. Check machine behavior when designing branches.

Pull-Based Flow

Plumbing uses a pull-based model, reagents don't flow on their own. A machine with an inlet actively pulls reagents from the outlets of other machines on the same network. If nothing is pulling, nothing moves.

This means:

  • An Input won't push reagents anywhere by itself. Another machine must pull from it.
  • A Synthesizer generates reagents into its buffer, but they sit there until something pulls.
  • A Tank pulls from its inlet network and stores reagents. Other machines then pull from the tank's outlet network.

Round-Robin Distribution

When a machine pulls reagents and there are multiple outlets on the same network (e.g., two synthesizers feeding a tank), it uses round-robin distribution. Each update tick, it starts pulling from a different outlet, cycling through them fairly.

Transfer Rate

Machines pull according to their configured transfer amount and update interval (generally 20u every 2 seconds). That pull budget is shared across all of a machine's inlets; adding more inlets splits access paths, not total pull budget.

Reactor: Targeted Pulling

The Reactor is special, it pulls specific reagents rather than everything. It fills each target reagent fully before moving to the next. If you set targets of 30u Iron and 20u Carbon, it will pull all 30u of Iron first, then pull Carbon.

Filter: Selective Routing

The Filter has one inlet and two outlets. It classifies intake into separate filtered and passthrough lanes, then controls which reagents are available on which outlet:

  • Filtered outlet: Only provides the reagents you've selected.
  • Passthrough outlet: Only provides reagents you haven't selected.

Because the lanes are separate, passthrough buildup will not prevent filtered reagents from being pulled into the machine.

Inline Filter: Selective Pulling

The Inline Filter pulls the same targeted way the reactor does. It has one inlet and one outlet, and only ever requests the reagents you've selected, so everything else stays on the network for machines further down the line. Use it when you want to tap a reagent out of a shared line without diverting the rest of it.

Unlike the reactor you don't set quantities, every selected reagent gets the same 10u allowance and its own room in the buffer, so an abundant reagent can't crowd the rest of your selection out.

Pill Press: Mixing Mode

In mixing mode, the pill press ignores its main inlet and instead pulls from its mixing inlets. Each mixing inlet pulls from its own separate network into a staging area. Once both staging areas have enough reagent, they combine and press a pill at the configured ratio.

Tips

  • Use the plunger to clear stuck reagents from any machine's buffer.
  • Machines only pull when they have space in their buffer. A full buffer stops pulling until reagents are pulled from it.
  • Use a buffer tank when you want reactor product fed back into a supply network for other reactors to use while also keeping a separate product output network for collection (dispenser/ChemMaster/etc.).
