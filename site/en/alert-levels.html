#Alert Levels

Alert levels represent the danger that is currently directed towards the station. There are 7 alert levels you should look out for.

Code Green: Standard alert at the start of the shift, no danger.

Code Blue: A danger has been shown to be present on the station

Code Red: There is active danger towards the station crew.

Code Gamma: There is a threat of total station destruction.

Code Delta: The onboard nuclear device has been armed, station destruction is imminent.

Code Yellow: There is an atmospheric or structural threat to the station.

Code Orange: The station has taken critical structural damage, and is unlikely to recover.

Code Violet: There is a biohazard threat on board the station.
