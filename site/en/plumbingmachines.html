Plumbing Machines

All plumbing machines are placed with the RPLD. Machines that require power must be within range of an APC.

Plumbing InputPlumbingInput

Plumbing OutputPlumbingOutput

Input and Output

Getting reagents into and out of the network

The Plumbing Input is a small tank you pour reagents into by hand. Other machines pull from it via the network. Connects in all directions.

The Plumbing Output is a small tank you can draw reagents from using a container. It pulls reagents from the network into its buffer. Connects in all directions.

Plumbing SinkPlumbingSink

Plumbing DrainPlumbingDrain

Sink and Drain

The plumbing classics.

The Plumbing Sink is more or less a combined input and output. Reagents drawn in from its inlets can be used to fill containers from its facet, and dumping reagents down the drain sends them into the network via its outlet.

The Plumbing Drain is a floor drain that absorbs puddles and routes them into the plumbing network. Connects in all directions.

Plumbing TankPlumbingTank

Tank

Buffering reagents in the network

The Plumbing Tank stores up to 2400u of reagents. Has one inlet and three outlets. Use tanks to buffer reagents between production stages or store large amounts of reagents.

Plumbing BufferPlumbingBuffer

Buffer

Aww cute!

The Plumbing Buffer stores up to 240u in a low-profile tank that can be walked over. It has one inlet and three outlets, with unconnected outlets for supplying seperate networks.

Plumbing FilterPlumbingFilter

Filter

Splitting reagents by type

The Plumbing Filter separates specific reagents from the network. Set which reagents to filter via its UI. It has one inlet and two outlets:

  • Filtered outlet for selected reagents.
  • Passthrough outlet for non-selected reagents.

The filter sorts incoming reagents into filtered and unfiltered internal containers, which can be pulled from the filtered and passthrough outlets respectively. It is capable of filtering off up to 4 unique reagents at a time. When disabled in the UI, all intake is treated as passthrough. Can be flipped via the RPLD.

Plumbing Inline FilterPlumbingInlineFilter

Inline Filter

Skimming reagents off a network

The Inline Plumbing Filter sits on a single run of duct with one inlet and one outlet, and draws specific reagents off it. Set which reagents to take via its UI.

Unlike the regular filter it does not sort what passes through it. Like the reactor, it only asks the network for the reagents you have selected, so everything else is left alone for machines further downstream. It takes up to 10 unique reagents and holds 10u of each, so a plentiful reagent fills its own allowance and then stops rather than hogging the machine. When disabled in the UI it stops pulling, though anything already in its buffer can still be drawn out. Its casing animates while reagents are actually flowing in, so an idle filter is easy to spot.

Plumbing ReactorPlumbingReactor

Reactor

Triggering chemical reactions automatically

The Plumbing Reactor pulls specific reagents from its inlet in configured quantities, heats them, and triggers reactions. Products are moved to the outlet. Has one inlet and one outlet. Set target reagents and quantities via the UI. Requires power. Use a plunger to clear stuck reagents.

Plumbing Pill PressPlumbingPillPress

Pill Press

Automated pill and patch production

The Plumbing Pill Press pulls reagents and presses them into pills or patches at a configurable dosage. Has one main inlet that pulls from the network normally, plus two optional mixing inlets that allow ratio-controlled mixing — set a percentage for each side to blend reagents from two separate networks. Toggle between pill and patch output via the UI. Requires power.

Plumbing SynthesizerPlumbingSynthesizer

Synthesizer

Generating reagents from power

The Plumbing Synthesizer generates basic reagents from an internal battery. Select a reagent from the UI and toggle it on. The battery charges while the machine is powered and drains as reagents are synthesized. Different reagents have different power costs.

Available reagents: Iron, Carbon, Copper, Hydrogen, Oxygen, Sugar, Silicon, Phosphorus.

Plumbing Smart DispenserPlumbingSmartDispenser

Smart Dispenser

Storing and dispensing reagents via labeled jugs

The Plumbing Smart Dispenser pulls all reagents from the network and stores up to 240u of each type. It pulls 40u per update, which is 2x the standard 20u pull rate used by most plumbing machines. Use a labeled jug on the dispenser to fill it with the matching reagent. Connects in all directions. Requires power.

Plumbing DisposalPlumbingDisposal

Disposal

Vaporizes unwanted reagents

The Plumbing Disposal has one inlet which it uses to pull reagents into an internal buffer, which are then destroyed over time. Use it to cleanly remove unwanted reagents from a duct network.
