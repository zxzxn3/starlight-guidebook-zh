操作控制

按键可以随时在 主菜单 → 设置 → 控制 中修改。下文以常用默认键位说明；如果你改过按键，以控制设置中显示的绑定为准。

界面

屏幕左上角是各个菜单按钮（Menu Buttons）及其对应快捷键。建议逐一查看它们的用途，尤其是表情菜单。

当管理员尝试联系你时，管理员帮助（Admin Help, AHelp） 按钮会变成红色。

动作栏

菜单按钮下方是动作栏（Action Bar），显示角色当前可以执行的通用动作和装备动作。将鼠标悬停在图标上可以查看用途。

动作栏同时也是快捷栏（Hotbar）。按对应的数字键即可执行动作。

可以拖动图标改变排列，也可以把图标拖离动作栏，暂时移除该动作。

状态栏

聊天窗口下方是状态栏（Status Bar），显示角色当前承受的状态。将鼠标悬停在图标上可以查看说明。

部分状态图标也可以点击。例如角色着火时会出现火焰图标，左键点击图标可以倒地翻滚灭火。被手铐束缚时，也可以用同样方式尝试挣脱。

物品栏

屏幕底部是物品栏（Inventory Bar），按从左到右的顺序包含以下装备与存储槽位：

  • 衣物栏（Clothing Inventory）：位于左下角，可用物品栏快捷键打开。包含眼睛、头部、颈部、面部、耳部、身体、外衣、手部和鞋子的槽位。
  • PDA 槽（PDA）：存放可用的 PDA；PDA 内可以放入证件和笔。
  • 腰带槽（Belt）：用于工具腰带和喷气背包。
  • 背部槽（Back）：通常用于挎包、背包和行李袋，也可以存放中型至大型武器以及标准尺寸的空气罐。
  • 手部槽（Hand）：可以视为物品的中转槽。
  • 口袋槽（Pocket）：适合存放需要快速取用的小型物品。
  • 宇航服存储槽（Suit Storage）：只有穿着宇航服、硬质宇航服或护甲时才能使用，主要用于空气罐和喷气背包，也可以存放枪械。

注意：非人形种族可能有少量不同的槽位。

移动

使用 WASD 移动角色。

携带的物品和负面状态会影响移动速度；按住 Shift 可以慢走。慢走会降低速度，也能避免踩到香蕉皮、液体等湿滑危险物时滑倒。

注意：可以在控制设置中把慢走改成开关模式。

太空行走

进入失重环境后仍能移动，只是摩擦力会降低。只要处于某个结构的可触及范围内，就可以继续移动。

如果完全漂离空间站进入太空，就需要利用运动规律，例如朝反方向投掷物品。

双手

角色双手由屏幕底部的手部槽表示。

  • 其中一只手始终是活跃手（Active Hand）。
  • 使用 X 切换活跃手。
  • 用活跃且为空的手左键点击物品，可以将其拿起。
  • 左键可以把活跃手中的物品放到别处，也可以根据情境对物品、机器或角色使用该物品。
  • 与世界互动前应留意当前活跃手，避免误用手中的物品。

物品不能通过拖放直接转移。

放下与投掷

使用 Q 将活跃手中的物品放下或放在手臂可及的位置。

使用投掷快捷键可以把物品投掷到鼠标位置。

拉动与推动

只要有一只空手，就可以拉动可移动的实体，包括物品、机器和玩家等生物。

  • 使用 Ctrl + 左键开始拉动。
  • 使用推动快捷键可以把被拉动的实体推向鼠标位置。
  • 使用释放快捷键或再次拉动同一实体即可松开。

也可以使用 Q 将活跃手拉动的实体放开。

交互

游戏包含六种根据情境变化的交互方式，可以通过不同方法触发。

标准交互与替代交互

左键执行标准交互（Standard Interaction）。结果取决于你手中的物品，以及点击的目标。

标准交互的范围很广：左键点击桌子可以放下手中物品；空手左键可以使用场景中的物体；最常见的情况则是用手持物品与角色或其他物品互动。

有时手持物品左键点击机器，可以直接交换物品。例如手持烧杯点击一台存有另一只烧杯的机器。空气罐和大型气罐也适用这一操作。

部分物品还提供替代交互（Alternative Interaction）。使用替代交互键可以锁定储物柜、弹出电池等内部物品。

激活交互

双手都拿着东西时，仍可以用激活交互（Activation）操作容器、门等物体。

例如无需先拿起容器就能打开容器，无需使用手持物品就能开门，也可以切换枪械模式。

对所有生物使用激活交互会打开脱衣菜单（Strip Menu），可以查看对方的物品栏，并尝试脱下或拿走其物品。

手持交互

许多物品可以使用手持交互（Use-in-hand）直接操作，例如打开瓶子、双手持握双手枪或大型近战武器、切换枪械模式，以及让注射器在抽取和注射之间切换。

可以左键点击活跃手执行标准手持交互，也可以使用替代手持交互。常用的两个默认键是 Z 和相应的替代交互键。

点击并拖动

按住左键把一个实体拖到另一个实体上，可以对该目标“使用”拖动的实体。拉动则使用 Ctrl + 左键。

常见用途包括：

  • 将玩家或 NPC 放到椅子、床、低温舱、处置装置等设施上。
  • 让自己爬上桌子；也可以对桌子使用替代交互键。
  • 把另一个生物拖到自己身上，打开脱衣菜单；也可以像前面所述使用激活交互。
  • 将清洁推车、水桶、烧杯等液体容器的内容物倒入另一个容器、排水口或机器。操作前必须先把容器放在地上，不能直接从物品栏倒出。

指向

使用指向键（默认鼠标中键）可以指向世界中的某个位置，所有玩家都会看到短暂出现的箭头。

小结

主要交互方式如下：

  • 标准交互：左键
  • 替代交互：替代交互键
  • 激活交互：激活键
  • 标准手持交互：Z
  • 替代手持交互：替代手持交互键
  • 点击并拖动

不需要死记所有组合。交互通常符合直觉，同类实体也往往使用一致的操作方式；多数实体只会用到一两种交互。

容器中的物品仍然可以直接互动。

上下文菜单

对任意可交互实体按右键可以打开上下文菜单（Context Menu），其中会列出当前可执行的其他互动，例如：

  • 将活跃手中容器的全部内容转移到另一个容器。
  • 按预设数量拆分物品堆。
  • 为化学品选择更精确的转移量。
  • 查看物体的拆解步骤。

在一堆重叠物品上按右键会打开实体菜单，列出可以正常互动的重叠实体。

检查

不确定某个物体或生物是什么时，可以使用 Shift + 左键检查。实体菜单中的物品也可以检查。

检查菜单除了显示实体描述，还会在右下角显示若干图标：

  • 问号：打开对应的 Guidebook 页面。
  • 闪电：查看物品属性。
  • 爱心：查看生物健康状况。
  • 其他可用信息。

物品栏与衣物

所有物品都可以对相应槽位使用左键来装备或卸下。

穿戴衣物最简单的方法是使用活跃手中的衣物并按 Z。部分物品不支持这种方式，需要手动放入正确槽位。

部分衣物拥有内部存储空间，可以像容器一样使用。

物品堆

对一叠物品使用替代交互键，可以直接把这叠物品对半拆分。

背部与腰带

如果装备了背包或腰带，可以使用激活交互键打开其物品栏，也可以点击图标右下角的小按钮。

还可以使用背包快捷键和腰带快捷键打开对应存储空间。

智能装备

可以在活跃手和对应槽位之间快速移动物品。如果该槽位内装有容器，智能装备（Smart-Equip）会快速存入或取出该容器中最近使用的物品；最近物品会显示金色星标。

  • 背包智能装备键用于背部槽。
  • 腰带智能装备键用于腰带槽。
  • 左右口袋和宇航服存储槽也分别有对应的智能装备键。

整理网格物品栏

拖动物品时可以重新排列位置。拖动过程中可以使用旋转键旋转物品。

在容器内对物品使用保存位置快捷键，可以保存它的位置。之后再次存入时，物品会回到保存的位置。将鼠标悬停在物品上可以查看已保存的位置。

摄像机

使用缩放快捷键可以放大和缩小视野，使用重置缩放键可以恢复默认缩放。

使用摄像机左转、右转快捷键可以旋转视野，使用摄像机重置键可以恢复默认方向。

注意：地图通常以默认摄像机方向进行设计。

更多控制细节可以在游戏 Wiki 中查看。
